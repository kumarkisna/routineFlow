---
name: Routine step details
description: Requirement and compatibility rule for multiple details on a routine step.
---

Each routine step keeps its existing detail and lets users add or remove additional detail entries on demand. Older steps with only one detail remain valid.

**Why:** The user asked for multiple step details without losing the existing single-detail behavior.

**How to apply:** Preserve the order of additional details when editing, copying, importing, and displaying routines.
