---
name: Custom palette placement
description: Placement preference for theme customization controls in Routine Flow.
---

Custom palette controls belong next to the preset selector inside each person's existing Theme settings. Do not create a separate palette tab.

**Why:** The user explicitly said they expect palettes near Theme in user settings and cannot rely on a separate Appearance page.

**How to apply:** Keep customization profile-scoped and expose its controls from each person's Theme section; avoid adding a new tab for palette editing.
