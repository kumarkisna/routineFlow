---
name: About guide maintenance
description: Keep the in-app how-to guide and its navigation aligned with current user-facing features.
---

When adding or removing user-facing features, update the About tab's how-to instructions and navigable jump links so the next build does not contain stale guidance.

**Why:** The user explicitly wants the About guide and its links to stay updated as features change.

**How to apply:** Include the relevant About guide update in feature work. Prefer a reliable shared source of truth or update mechanism when working on the separately tracked guide-synchronization task.
